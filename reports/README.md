# Report

[Read the report](report.pdf): **Accuracy and Efficiency Tradeoffs of Random Forest, Support Vector Machine, and k-Nearest Neighbour Classifiers on Two Datasets, and the Effects of Sample Reduction**.

Authors: Antonio Gutiérrez, Arnau Martínez, Lucas King and Miguel Ruiz. The PDF retains its title, authorship, academic context and bibliography, unchanged.

Its measurements are in [`results/reference/`](../results/reference/). [The results guide](../docs/results.md) makes the tables and figures easier to navigate.

For precise implementation details, use the code and [method guide](../docs/statistical-analysis.md). The data are the 178-case **Wine** dataset, not Wine Quality as some PDF passages call it. References to per-instance latency should be read as fold-processing time divided by test cases; isolated-query latency is not measured.
